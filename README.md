# Bike Buyers Analysis

## *(Excel · Python · R · Power BI · Streamlit )*

## 🌐 Live Streamlit App
Streamlit app for automated data cleaning checks and exploratory data analysis.
https://customerpurchaseanalysisanddashboard-8kjnv3tj6khyhzsycm5zlh.streamlit.app/

Played around with a dataset of bike buyers: cleaned it up, ran EDA, and built dashboards. Excel, R, and Python; while Power BI and Streamlit made things interactive. It's basically: clean, explore, visualize.

## Project Files & Structure


```

```
